1"""Pluggable LLM backend package. 

2 

3Two interchangeable entry points for the same functionality: 

4 

5- **Object-style** (preferred for production code): :func:`get_llm_backend` 

6 returns the :class:`LLMBackend` configured for the active settings; call 

7 ``.direct(...)``, ``.streaming(...)``, ``.chat(...)`` on it. The factory 

8 dispatches on ``cfg.llm_provider`` so swapping providers does not touch 

9 call sites. 

10- **Function-style** (helper for code with only a base URL in scope, used 

11 by ``tests/performance/`` and ``evals/``): :func:`call_llm_direct`, 

12 :func:`call_llm_streaming`, :func:`chat_with_messages` take a base URL 

13 and construct an :class:`OllamaBackend` internally. 

14 

15Other public names: :class:`OllamaBackend`, :class:`OpenAICompatibleBackend`, 

16:class:`ToolsNotSupportedError` (raised when a model rejects native tool 

17calling so the reply engine can fall back to text-based), and 

18:func:`extract_text_from_response` (normalises content across known 

19response shapes). 

20 

21``import requests`` is re-exported so tests that patch 

22``jarvis.llm.requests.post`` to intercept HTTP traffic work without 

23reaching into the per-backend modules. 

24"""
